# Practica 0 - Repaso Haskell

## Ejercicio 1

Me piden dar el tipo y describir el comportamiento de algunas funciones predefinidas en el módulo prelude de haskell

### `null`
```hs
ghci> :t null
null :: Foldable t => t a -> Bool
```
Indica si el argumento es nulo, en el caso de listas devuelve true si la lista es vacía
```hs
ghci> null []
True
ghci> null [1,2,3]
False
```

### `head`
```hs
ghci> :t head
head :: GHC.Internal.Stack.Types.HasCallStack => [a] -> a
```
Devuelve el primer elemento de una lista. Es una función parcial, si la lista no tiene elementos devuelve un error
```hs
ghci> head [1,2,3]
1

ghci> head []
*** Exception: Prelude.head: empty list
```

### `tail`
```hs
ghci> :t tail
tail :: GHC.Internal.Stack.Types.HasCallStack => [a] -> [a]
```
Función que toma una lista como argumento y devuelve la lista que surge de eliminar el primer elemento de la lista pasada como argumento. Es una función parcial, si la lista es vacía tira una exception
```hs
ghci> tail [1,2,3]
[2,3]

ghci> tail []
*** Exception: Prelude.tail: empty list
```

### `init`
```hs
ghci> :t init
init :: GHC.Internal.Stack.Types.HasCallStack => [a] -> [a]
```
Dada una lista devuelve la lista que surge de eliminar el último elemento de la lista original. Es una función parcial, si la lista es vacía tira exception
```hs
ghci> init [1,2,3]
[1,2]

ghci> init []
*** Exception: Prelude.init: empty list
```

### `last`

```
ghci> :t last
last :: GHC.Internal.Stack.Types.HasCallStack => [a] -> a
```
Toma una lista y devuelve su último elemento. Si la lista es vacía tira exception.
```hs
ghci> last [1,2,3]
3

ghci> last []
*** Exception: Prelude.last: empty list
```

### `take`
```hs
ghci> :t take
take :: Int -> [a] -> [a]
```
Toma un entero $n$ y una lista y devuelve la lista que contiene los primeros $n$ elementos de la lista original. Si la lista es vacía devuelve la lista vacía. Si el entero es 0 devuelve la lista vacía.

```hs
ghci> take 2 [1,2,3]
[1,2]

ghci> take 3 []
[]

ghci> take 3 [1,2,3]
[1,2,3]
```

### `drop`
```hs 
ghci> :t drop
drop :: Int -> [a] -> [a]
```
Toma un entero $n$ y una lista y devuelve la lista que surge de eliminar los primeros $n$ elementos de la lista
```hs
ghci> drop 1 [1,2,3]
[2,3]
ghci> drop 0 [1,2,3]
[1,2,3]
ghci> drop 3 [1,2,3]
[]
```

### `(++)`
```hs
ghci> :t (++)
(++) :: [a] -> [a] -> [a]
```
Toma dos listas y las junta en una sola
```hs
ghci> [1,2] ++ [3,4]
[1,2,3,4]

-- O como funcion
ghci> (++) [1] [2,3,4]
[1,2,3,4]
```

### `concat`
```hs
ghci> :t concat
concat :: Foldable t => t [a] -> [a]
```
Toma una lista de listas y concatena todos los elementos de la lista en una sola

```hs
ghci> concat [[1,2], [3,4]]
[1,2,3,4]

ghci> concat ["Hello ", "World"]
"Hello World"
```

### `reverse`
```hs
ghci> :t reverse
reverse :: [a] -> [a]
```
Toma una lista y devuelve la lista que surge de revertir el orden de todos sus elementos
```hs
ghci> reverse [1,2,3]
[3,2,1]
```

### `elem`
```hs
ghci> :t elem
elem :: (Foldable t, Eq a) => a -> t a -> Bool
```
Toma un elemento y una lista y devuelve true si el elemento es parte de la lista.
```hs
ghci> elem 1 [1,2,3]
True
ghci> elem 0 [1,2,3]
False
```

## Ejercicio 2

### `valorAbsoluto`
```hs
valorAbsoluto :: Float -> Float
valorAbsoluto x = if x < 0 then x * (-1) else x
```

### `bisiesto`
Un año es bisiesto si es divisible entre 4, pero no entre 100, a menos que también sea divisible entre 400.
```hs
bisiesto :: Int -> Bool
bisiesto año = (rem año 4 == 0 && rem año 100 /= 0) || rem año 400 == 0
```

### `factorial`
```hs
factorial :: Int -> Int
factorial 0 = 1
factorial n = n * factorial (n-1)
```

### `cantDivisoresPrimos`
```hs
cantDivisoresPrimos :: Int -> Int
cantDivisoresPrimos 1 = 0
cantDivisoresPrimos x = cantDivisoresPrimosEnRango x [2..x] -- Esto se puede mejorar, no es necesario chequear hasta x :)

cantDivisoresPrimosEnRango :: Int -> [Int] -> Int
cantDivisoresPrimosEnRango _ [] = 0
cantDivisoresPrimosEnRango n (x:xs) =
    if rem n x == 0
        then 1 + cantDivisoresPrimosEnRango (eliminarTodasLasApariciones n x) xs
        else cantDivisoresPrimosEnRango n xs

eliminarTodasLasApariciones :: Int -> Int -> Int
eliminarTodasLasApariciones n x =
    if rem n x == 0
        then eliminarTodasLasApariciones (div n x) x
        else n
```

## Ejercicio 4

### `limpiar`

```hs
limpiar :: String -> String -> String
limpiar xs [] = []
limpiar xs (y:ys) =
    if elem y xs
        then limpiar xs ys
        else y : limpiar xs ys

```

### `difPromedio`

```hs
difPromedio :: [Float] -> [Float]
difPromedio xs = calcularDiferencias (average xs) xs

calcularDiferencias :: Float -> [Float] -> [Float]
calcularDiferencias avg [] = []
calcularDiferencias avg (x:xs) = (x - avg) : calcularDiferencias avg xs

average :: [Float] -> Float
average xs = sum xs / fromIntegral (length xs)
```

### `todosIguales`
```hs
todosIguales :: [Int] -> Bool
todosIguales [] = True
todosIguales [x] = True
todosIguales (x:y:ys) = x == y && todosIguales ys
```
